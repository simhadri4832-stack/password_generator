# Password Generator Project

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Main Features
1. Generate random passwords.
2. Select password length from 6 to 40 characters.
3. Include uppercase letters.
4. Include lowercase letters.
5. Include numbers.
6. Include symbols.
7. Password strength indicator.
8. One-click copy button.
9. Responsive design for mobile, tablet and desktop.
10. No database or server required.

## How to Run
1. Open the folder in VS Code.
2. Open `index.html` in a browser.
3. Click "Generate Password".
4. Select the required options.
5. Click the copy button to copy the password.

## Project Objective
The objective of this project is to create a simple browser-based tool that helps users generate stronger passwords by combining different character types and adjustable password length.

## Important Note
This is a client-side educational project. Passwords are generated in the browser and are not stored by this project.
